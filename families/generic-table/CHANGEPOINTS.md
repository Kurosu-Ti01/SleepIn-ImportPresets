# 变化点清单 · generic-table（通用抓取）

这是长尾兜底：认不出教务系统时，让用户自己打开课表页，脚本读**当前页面**上那张表。它不发请求，也没有学校身份，
对应应用里的「通用工具」分类 —— 所以把它当成「试试看」的入口，而不是正式适配。

| 变化点 | 默认取值 | 说明 |
|---|---|---|
| `tableSelectors` | `#timetable` / `#kbtable` / `table[id*='kb' i]` / … / `table` | 课表表格的候选选择器，**依次尝试**；最后一项是「页面上任何一张表」 |
| `headerRowSectionSelectors` | `td:first-child` 等 | 行头（节次那一列）的选择器 |
| `blockSplitter` | `-----` | 一个格子里多门课之间的分隔线 |
| `fieldTitles.*` | `老师/教师/授课教师`、`教室/上课地点/地点`、`周次(节次)` 等 | 内联标签的 title 候选文案 |
| `sectionPattern` | `\[(\d+)(?:-(\d+))?节\]` | 从「周次(节次)」里抠节次的正则 |
| `dayColumnOffset` | `1` | 第几列开始是周一 |
| `dayCount` | `7` | 表格里最多几列算星期 |
| `assumedTotalWeeks` | `20` | 总周数假设值（通用抓取无从得知，只会显示在确认弹窗里） |
| `semesterYears` | `4` | 本地合成的学期候选数量 |
| `sectionTimesFromTableHeader` | `true` | 从行头读作息时间 |
| `mergeAdjacentSections` | `true` | 相邻节次合并 |

## 它的假设（不满足就用不了）

**一张表，行是节次（行头写着「第 1-2 节」），列是星期。** 这是最常见的那种课表布局。

不满足的情况都属于正常的失败：布局不同、课表不是表格、课表在 iframe 里、或者页面还没登录到课表页 ——
这时它会明确说「当前页面上没有找到课表表格」，而不是导入一张空课表。这类学校需要自己的族，或自己写脚本。

## 什么时候该用它

- 用户的学校不在已适配列表里，且课表是标准的表格布局 → 值得一试；
- 试不出来 → 走「导入自己的脚本」这条路（应用里已有入口）。

**它不是正式方案**：没有维护者、没有实测记录，也不应该被写进「已适配学校」的条目里。
