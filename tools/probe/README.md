# 探测脚本：快速看清一个教务系统长什么样

`portal-recon.js` 在浏览器控制台里跑一遍，就会把当前这套教务系统的形状整理成一段**脱敏报告**：
请求路径、参数名、响应里的字段名，以及每个值的**形状**（是文本还是位图、是范围还是列表）。

报告按设计可以贴到聊天窗口或公开 Issue 里，所以第一节先讲清楚它拿走了什么、没拿走什么。

---

## 一、隐私：脚本会拿走什么、不会拿走什么

脚本：

- **不发送任何请求**。它只观察页面自己发出的请求与响应，不发数据到任何地方。
- **不读取** Cookie、localStorage、密码、表单内容。
- **不截图**，不碰剪贴板。

报告里**只有**：

| 保留 | 说明 |
|---|---|
| 请求路径 | 例如 `/jsxsd/xskb/xskb_list.do`。里面 5 位以上的数字串会被打码（学号就藏在这种地方） |
| 参数名与字段名 | `xnxq01id`、`kcmc`、`zcd` 这些**名字** |
| 值的**形状** | 汉字→`中`、字母→`a`、数字→`9`。`1-16周(单)` 变成 `9-99中(中)`，`高等数学` 变成 `中中中中` |

也就是说：**能看到「这是一个什么样的值」，看不到「这个值是什么」。**

报告里**没有**：课程名、教师姓名、学号、截图、页面标题原文（只报命中了哪些厂商关键词）。

脚本还会在输出前**自己检查一遍**（`assertRedacted`）：规则之外认不出的字符（`〇`、希腊字母、假名这类）
会被换成形状标记（字母→`a`、数字→`9`、汉字→`中`），码位写进报告的 `redaction.unresolved`，
同时在控制台打一条警告。也就是说**报告总是给得出来**，而里面始终不会有原文；只有报告根本组装不出来时
才会什么都不输出。

> 要请别人代跑时，这一节可以直接整段转过去：他要判断的就是「愿不愿意在自己的会话里跑它」。

## 二、怎么跑

Chrome / Edge / Firefox 都可以：

1. 用电脑浏览器打开**教务系统**，正常登录。
2. 按 `F12` 打开开发者工具（Mac 是 `Option + Command + I`），点 **Console / 控制台**。
3. 打开 `portal-recon.js`，**整段复制**，粘到控制台里回车。
   - 浏览器可能提示「允许粘贴」，输入 `allow pasting` 即可。
4. **点到「课表查询」页面**，等课表显示出来；然后在课表页上改一下学年/学期，再点一次「查询」。
   - 脚本只能看到**装好之后**发出的请求：进页面时那次自动加载已经过去了。漏了这一步，
     报告里的 `requests` 会是空的。
   - 如果课表是在页面内的一个小窗口（iframe）里：控制台左上角有一个执行上下文下拉框，
     切到那个 iframe，再粘一次这段脚本。
5. 回到控制台，运行：

   ```js
   __sleepinRecon.copy()      // 复制报告到剪贴板（推荐）
   __sleepinRecon.download()  // 或者存成 sleepin-portal-recon.json 文件
   ```

   报告到手了：自己写预设就直接照着读；要请人一起判断就把它贴出去。

如果控制台里出现「警告：有 N 种字符不在常规脱敏规则内」，把报告连同这条警告一起保留即可：
报告里没有原文，警告给出的是这些字符的码位（`U+XXXX`）。

需要重跑（比如上次忘了点查询）时，先刷新页面，或在控制台执行 `delete window.__sleepinRecon`：
脚本第二次粘贴会直接跳过安装，不这样处理就看不到新请求。

不想粘脚本也可以走手动路线（见第五节）。

## 三、报告里能看出什么

拿到报告后，按这个顺序读：

| 报告字段 | 它回答的问题 | 对应到预设里 |
|---|---|---|
| `page.path` | 课表页在哪 | 方案的 `description`，以及 `detect` 的判断条件 |
| `page.hostIsEduCn` | 域名是不是 `edu.cn` 下 | 关系到应用的明文 HTTP 放行规则（只对 `.edu.cn`） |
| `requests[].path` | 课表数据是哪个请求返回的 | 族的 `scheduleAction` |
| `requests[].method` + `query` + `requestBody` | 请求怎么发、带哪些参数 | `postForm`/`get`，参数名变化点 |
| `requests[].json` | JSON 响应的键与值的形状 | `fields.*` 映射 |
| `requests[].rowArrays[].path` | 课表行数组在哪个键下 | `rowContainer.path`（这一项能省掉一轮来回） |
| `requests[].html.looksLikeTimetable` | 课表是不是 HTML 表格 | 决定走 JSON 族还是 HTML 族 |
| `windowGlobals[]` | 课表是不是写在页面脚本的全局变量里（不发请求） | 需要单独的取值方式 |
| `familyHints` / `vendorMarks` | 可能是哪家的系统 | 选族的起点（**只是启发**） |
| 值形状里的 `9-99中` | 周次是文本还是位图 | `weeksEncoding` |
| 值形状里的 `binary(len=20,ones=4)` | 位图周次，共 20 周（`ones` 只是数量，不含「哪几周」） | `weeksEncoding: "bitmap"` + `assumedTotalWeeks` |
| `redaction.unresolved` | 有没有规则外认不出的字符（码位 + 类别） | 该不该给脱敏规则补一段；有值时先看它再看别的 |

**判断「框架设计合不合理」正是靠这张表**：如果报告里的每一项都能落进某个取值或某个环节，
说明这个族/变化点的模型够用；如果反复出现「报告里很清楚、但预设里无处安放」的东西，
那就是模型缺了一块，应该先补模型，而不是给这一所学校写死代码。

## 四、改这个脚本时不能破坏的三条

1. **不主动发请求**。它只能观察，不能替使用者去访问任何地址。
2. **不读凭据**。Cookie、localStorage、表单值都不碰。
3. **所有值都必须过 `brief()`**，它在返回前调 `assertRedacted()` 自检；自检认不出的字符要走兜底
   （换成形状标记 + 把码位记进报告的 `redaction.unresolved`）——**不能原样输出，也不能让整份报告消失**，
   拿不到报告就无从定位；这条路径不能被各处「出错了就降级」的 `catch` 吞掉
   （用 `redactionError` 标记，见代码注释）。

改了脱敏规则或报告结构时，下面两个测试文件必须在 `node --test` 里全绿：

- `tests/recon-redaction.test.mjs`：一条是「往夹具里放课程名、姓名、学号，然后断言报告里搜不到它们」；
- `tests/probe-smoke.test.mjs`：用假 DOM 把浏览器分支真跑一遍（它挡下过两次真实缺陷，
  一次是 IIFE 没传参导致一粘就崩，一次是自检错误被降级 catch 吞掉）。

这是这个脚本唯一真正危险的失败方式，不要绕过或放宽。

## 五、备用路线：不想在控制台里粘脚本

在控制台 **Network / 网络** 面板里操作：

1. 在课表页刷新一下，找到返回课表数据的那条请求（通常是列表里最大的一条，或名字里带 `kb`、`schedule` 的）；
2. 点它，把 **Request URL** 与 **Payload / Query String** 里的**参数名**记下来；
3. 切到 **Response**：如果是 JSON，只把**键名**留下来（不要值）；
   如果是 HTML，用 DevTools 的 Elements 面板找到课表那张 `<table>`，把它的 `id`/`class` 与
   前两行的**标签结构**记下来即可。

无论自用还是贴给别人：**不要整段响应、不要课表截图、不要任何含姓名或学号的内容。**
实在只能拿到原始响应时，先删掉所有值——需要知道的只是键名与形状。
